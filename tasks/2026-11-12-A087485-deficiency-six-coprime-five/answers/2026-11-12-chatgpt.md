# OEIS A087485: Status and Proof Attempt

**Research date:** 12 November 2026 **Problem:** Existence of an odd integer $m>7$ satisfying

$$
2m-\sigma(m)=6,\qquad \gcd(m,5)=1.
$$

**Overall finding:** The conjecture appears to remain open. However, I obtained a reproducible computer-assisted result: **every solution other than $7$ must have at least 10 prime factors, counted with multiplicity, if it is coprime to $5$.** This restriction is independent of the numerical size of $m$.

OEIS A087485 lists the odd integers satisfying $2m-\sigma(m)=6$:

\sigma(m)=2m-6,\quad5\nmid m.}

It is well-posed. The $n>1$ condition excludes the already-known solution $m=7$, since $a(1)=7$.

## 2. Proof and partial results

I found no proof of the full conjecture. The following two restrictions are established here.

### 2.1 Elementary theorem: excluding both 3 and 5 requires at least 15 distinct prime factors

**Theorem 1 (proved).** Suppose $m>7$ is odd and

$$
\sigma(m)=2m-6,\qquad \gcd(m,15)=1.
$$

Then

$$
\boxed{\omega(m)\geq15,}
$$

where $\omega(m)$ counts distinct prime factors.

**Proof.**

Write

$$
m=\prod_{i=1}^{k}p_i^{e_i},\qquad
7\leq p_1<p_2<\cdots<p_k.
$$

By multiplicativity of the divisor-sum function,

$$
\frac{\sigma(m)}m
=\prod_{i=1}^{k}
\left(1+\frac1{p_i}+\cdots+\frac1{p_i^{e_i}}\right)
<\prod_{i=1}^{k}\frac{p_i}{p_i-1}.
$$

But our equation implies

$$
\frac{\sigma(m)}m=2-\frac6m.
$$

First suppose $k=1$. If $m=p$ is prime, the equation gives $p-1=6$, hence $p=7$, which is excluded by $m>7$. If $m=p^e$ with $e\geq2$, then

$$
2m-\sigma(m)>
p^e\left(2-\frac p{p-1}\right)
\geq49\cdot\frac56>6,
$$

also impossible.

Now suppose $2\leq k\leq11$. The product of $p/(p-1)$ is maximized by choosing the smallest admissible distinct primes. Thus

$$
\frac{\sigma(m)}m
<
\prod_{p\in\{7,11,\ldots,43\}}\frac p{p-1}
<1.882.
$$

On the other hand, $m\geq7\cdot11=77$, giving

$$
\frac{\sigma(m)}m
=2-\frac6m
\geq 2-\frac6{77}
>1.922,
$$

a contradiction.

Finally, suppose $12\leq k\leq14$. The corresponding upper bound is

$$
\frac{\sigma(m)}m
<
\prod_{p\in\{7,11,\ldots,59\}}\frac p{p-1}
<1.994.
$$

Because $m$ has at least 12 distinct prime factors,

$$
m\geq7\cdot11\cdots47
=20496326086283047.
$$

Consequently,

$$
2-\frac6m>1.994,
$$

again a contradiction.

Every possibility with $k\leq14$ has been excluded. Therefore $\omega(m)\geq15$. $\square$

This establishes an unconditional structural restriction without using the OEIS computational bounds.

### 2.2 Computer-assisted theorem: at least 10 prime factors if 5 does not divide $m$

**Theorem 2 (finite exhaustive computation).** For odd positive integers $m$ satisfying

$$
5\nmid m,\qquad \sigma(m)=2m-6,
$$

the only solution with $\Omega(m)\leq9$ is $m=7$, where

$$
\Omega(m)=\sum_{p^e\parallel m}e.
$$

Equivalently,

$$
\boxed{m>7,\quad5\nmid m,\quad
\sigma(m)=2m-6
\implies\Omega(m)\geq10.}
$$

The exhaustive program appears in Section 3. Here is the mathematical justification for its completeness.

**Branch representation.**

Every odd integer has a unique ordered prime-power factorization. We enumerate these factorizations recursively, never admitting the prime $5$.

At any stage, suppose the already selected prime powers have product $n$, with $\sigma(n)=s$, and exactly $r$ prime factors (counted with multiplicity) remain to be selected.

If $s\geq2n$, no nonempty coprime extension can solve the equation, because adjoining prime powers strictly increases $\sigma(n)/n$. Such branches are discarded.

**Rigorous pruning inequality.**

Let $p$ be the smallest prime factor of the remaining part. The final number $M$ satisfies

$$
M\geq np^r.
$$

Every remaining prime is at least $p$, so

$$
\frac{\sigma(M)}M
\leq\frac sn
\left(\frac p{p-1}\right)^r.
$$

But any solution must satisfy

$$
\frac{\sigma(M)}M
=2-\frac6M
\geq2-\frac6{np^r}.
$$

Therefore the branch is impossible whenever

$$
\frac sn\left(\frac p{p-1}\right)^r
<2-\frac6{np^r}.
$$

Clearing positive denominators gives the exact integer test

$$
\boxed{
sp^{2r}<
(2np^r-6)(p-1)^r.
}
$$

The left-hand ratio bound decreases as $p$ increases, whereas the required lower bound increases. Consequently, once this test excludes a prime $p$, it excludes every larger prime as well.

Since all retained prefixes satisfy $s/n<2$, the test must eventually succeed as $p\to\infty$. Hence every search branch terminates.

**Last-prime shortcut.**

When $r=1$, the remaining factor must be a single prime $p$. The equation becomes

$$
s(p+1)=2np-6,
$$

so necessarily

$$
\boxed{p=\frac{s+6}{2n-s}.}
$$

Thus there is at most one candidate final prime, which can be tested exactly for integrality, ordering, divisibility by 5, and primality.

Together, these observations prove that the program performs a finite, exhaustive search for each prescribed value of $\Omega(M)$, regardless of the numerical magnitude of $M$.

The executed program found no eligible solutions for $\Omega=2,\ldots,9$. The case $\Omega=1$ gave only $7$.

**This is a computer-assisted proof of Theorem 2**, subject to the usual requirement that the implementation and reported execution be independently checked. It does not establish whether qualifying numbers with ten or more prime factors exist.

## 3. Computational verification

### 3.1 Complete search by number of prime factors

The following is the exact standalone Python program used for Theorem 2. It requires only the standard library, uses arbitrary-precision integer arithmetic, and tests primality deterministically by trial division.

```python

from math import isqrt

def isprime(n):
    if n < 2: return False
    for d in range(2, isqrt(n) + 1):
        if n % d == 0: return False
    return True

def nextprime(n):
    n += 1
    while not isprime(n): n += 1
    return n

def run(K):
    nodes, solutions = 0, []

    def dfs(n, s, last, r):
        nonlocal nodes
        nodes += 1

        if r == 0:
            if 2*n - s == 6:
                solutions.append(n)
            return

        if r == 1:
            d = 2*n - s
            if d > 0 and (s+6) % d == 0:
                p = (s+6) // d
                if p > last and p != 5 and isprime(p):
                    solutions.append(n*p)
            return

        p = nextprime(last)
        while True:
            if p == 5:
                p = nextprime(p)
                continue

            if s*p**(2*r) < (2*n*p**r - 6)*(p-1)**r:
                break

            power, sigma_power = 1, 1
            for e in range(1, r+1):
                power *= p
                sigma_power += power
                if s*sigma_power < 2*n*power:
                    dfs(n*power, s*sigma_power, p, r-e)

            p = nextprime(p)

    dfs(1, 1, 2, K)
    return nodes, sorted(solutions)

for K in range(1, 10):
    nodes, terms = run(K)
    print(f"Omega={K}: nodes={nodes}, solutions={terms}")
```

### 3.2 Independent direct divisor-sum sieve

I also compiled and ran a C++17 sieve that computes $\sigma(m)$ for every odd integer up to $20,000,000$, independently of the factorization search.

```

#include <cstdint>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    const uint32_t N = 20000000;
    vector<uint32_t> sig(N/2 + 1, 0);

    for (uint64_t d = 1; d <= N; d += 2)
        for (uint64_t m = d; m <= N; m += 2*d)
            sig[m/2] += d;

    cout << "All: ";
    for (uint64_t m = 1; m <= N; m += 2)
        if (2*m - sig[m/2] == 6)
            cout << m << " ";

    cout << "\nCoprime to 5: ";
    for (uint64_t m = 1; m <= N; m += 2)
        if (m % 5 && 2*m - sig[m/2] == 6)
            cout << m << " ";
    cout << "\n";
}
```

The odd-divisor sieve works because the divisors of an odd integer are all odd.
