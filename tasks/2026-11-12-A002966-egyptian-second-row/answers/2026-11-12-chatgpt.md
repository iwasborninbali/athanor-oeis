# OEIS A002966 — Egyptian Fractions, Second Row

**Research report — 12 November 2026**

## 1. Status: proved, not an open conjecture

**Verdict: The conjecture attributed to D. S. McNeil is true, and its resolution is already documented in OEIS.** It follows from an elementary geometric identity. The conjecture should no longer be classified as open.

### 1.1 Precise statement

Define

$$
T(r,m)=\#\left\{(x_1,\ldots,x_m)\in\mathbb Z_{>0}^m:
x_1\le\cdots\le x_m,\quad
\sum_{i=1}^{m}\frac1{x_i}=\frac1r
\right\}.
$$

The comment by R. J. Mathar (6 May 2010) in [OEIS A002966](https://oeis.org/A002966) conjectures that the second row of this array equals [OEIS A003167](https://oeis.org/A003167).

Let $a(m)$ denote A003167, whose definition is the number of $m$-dimensional rectangular cuboids with positive integral edge lengths, counted up to permutation of the edges, whose hypervolume equals their total boundary hyperarea.

The precise claim is

$$
\boxed{T(2,m)=a(m)\qquad(m\ge2).}
$$

The restriction $m\ge2$ is an indexing detail: A003167 starts at $m=2$, whereas $T(2,1)=1$ is also defined.

### 1.2 Existing resolution

The decisive source is:

**Lewis Chen (20 December 2019), comment in OEIS A003167**, which explicitly gives this alternative interpretation:

> Number of nondecreasing tuples (x_1, x_2, ..., x_n) such that 1/2 = 1/x_1 + 1/x_2 + ... + 1/x_n.



This is exactly the definition of $T(2,n)$. Thus the supposed conjecture has appeared as an established alternative interpretation in the sequence's own entry since 2019.

An earlier related reference is J. F. T. Rabago and R. P. Tagle (2013), *On the Area and Volume of a certain Rectangular Solid and the Diophantine Equation 1/2=1/x+1/y+1/z*, *Notes on Number Theory and Discrete Mathematics*, volume 19, number 3, pages 28–32. It concerns the three-dimensional instance.

These establish historical precedence. The proof below is therefore an independent verification of a known result, **not a claim of mathematical novelty**.

## 2. Proof

**Theorem (known).** For every integer $m\ge2$,

$$
T(2,m)=\mathrm{A003167}(m).
$$

**Proof.**

Consider an $m$-dimensional axis-aligned rectangular cuboid with positive integer edge lengths

$$
x_1\le x_2\le\cdots\le x_m.
$$

Its $m$-dimensional hypervolume is

$$
V=\prod_{i=1}^{m}x_i.
$$

Its boundary consists of two $(m-1)$-dimensional facets perpendicular to each coordinate direction. Its total boundary hyperarea is therefore

$$
S=2\sum_{i=1}^{m}\prod_{j\ne i}x_j.
$$

Since every $x_i>0$, division by $V$ is valid, giving

$$
\frac{S}{V}=2\sum_{i=1}^{m}\frac1{x_i}.
$$

Consequently,

$$
\begin{aligned}
V=S
&\iff \frac{S}{V}=1\\
&\iff 2\sum_{i=1}^{m}\frac1{x_i}=1\\
&\iff \sum_{i=1}^{m}\frac1{x_i}=\frac12.
\end{aligned}
$$

Every unordered collection of integer edge lengths has a unique nondecreasing ordering. Thus this equivalence establishes a bijection between:

- $m$-dimensional integer cuboids with $V=S$, counted up to permutation of edge lengths;
- nondecreasing $m$-tuples of positive integers whose reciprocals sum to $1/2$.

The first set is counted by A003167, and the second by $T(2,m)$.

Therefore

$$
\boxed{T(2,m)=\mathrm{A003167}(m)}
$$

for every $m\ge2$. $\square$

**Proof status:** Complete, unconditional, and elementary. No asymptotic assumption, computational verification, or unresolved number-theoretic problem is involved.

The only interpretive assumption is the standard OEIS convention that cuboids differing only by a permutation of their edge lengths are counted once. The examples in A003167 confirm this convention.

## 3. Computational verification

**Result: All five published terms of A003167 were reproduced exactly.**

I ran an exact-integer Python program implementing the Egyptian-fraction recurrence, with a divisor-based shortcut for the last two denominators.

For a reduced positive fraction $p/q$, the final equation

$$
\frac pq=\frac1x+\frac1y
$$

is equivalent to

$$
\boxed{(px-q)(py-q)=q^2.}
$$

Thus the last two denominators can be enumerated by divisors of $q^2$, avoiding potentially enormous denominator searches.

The program separately checks this divisor identity against direct enumeration for 3,324 parameter combinations.

### Reproducible Python program

```python

from functools import cache
from math import gcd

@cache
def square_divisors(q):
    n, ds, d = q, [1], 2
    while d*d <= n:
        if n % d == 0:
            e = 0
            while n % d == 0:
                n //= d
                e += 1
            ds = [v*d**j for v in ds for j in range(2*e+1)]
        d += 1 if d == 2 else 2
    if n > 1:
        ds = [v*n**j for v in ds for j in range(3)]
    return ds

def pairs(p, q, lo):
    return sum(d <= q and (d+q) % p == 0 and
               (q*q//d+q) % p == 0 and (d+q)//p >= lo
               for d in square_divisors(q))

@cache
def count(p, q, lo, k):
    if k == 1:
        return int(q % p == 0 and q//p >= lo)
    if k == 2:
        return pairs(p, q, lo)
    total = 0
    for x in range(max(lo, q//p+1), k*q//p+1):
        a, b = p*x-q, q*x
        g = gcd(a, b)
        total += count(a//g, b//g, x, k-1)
    return total

def brute_pairs(p, q, lo):
    result = 0
    for x in range(max(lo, q//p+1), 2*q//p+1):
        a, b = q*x, p*x-q
        result += (a % b == 0 and a//b >= x)
    return result

trials = 0
for q in range(2, 31):
    for p in range(1, q):
        if gcd(p, q) == 1:
            for lo in range(1, 13):
                assert pairs(p, q, lo) == brute_pairs(p, q, lo)
                trials += 1
print('Pair lemma checks:', trials, 'PASS')
print('m T(2,m) A003167 equal')
for m, expected in enumerate((2, 10, 108, 2892, 270332), start=2):
    got = count(1, 2, 1, m)
    print(m, got, expected, got == expected)
```
