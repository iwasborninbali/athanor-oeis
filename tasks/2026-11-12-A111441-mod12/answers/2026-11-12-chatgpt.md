## 2. Полное доказательство (PROVED)

Пусть $q_1=2,q_2=3,q_3=5,\ldots$ — последовательность простых чисел, а

$$
S_m(k)=\sum_{i=1}^{k}q_i^m,\qquad m\ge1.
$$

Определим

$$
A_m=\{k\ge1:k\mid S_m(k)\}.
$$

**Теорема.** Для любого положительного целого $m$ и любого простого $p$, удовлетворяющего условию

$$
\boxed{p-1\mid m},
$$

ни один элемент $A_m$ не делится на $p$.

Это достаточное условие, а не утверждение о том, что никакие другие простые делители не могут быть исключены дополнительными аргументами.

### Доказательство

По малой теореме Ферма для каждого простого $q\ne p$

$$
q^{p-1}\equiv1\pmod p.
$$

Поскольку $m=t(p-1)$, где $t\ge1$, получаем

$$
q^m\equiv
\begin{cases}
0\pmod p,&q=p,\\
1\pmod p,&q\ne p.
\end{cases}
$$

Обозначим через $r=\pi(p)$ порядковый номер простого $p$, то есть $q_r=p$.

Рассмотрим два случая.

**Случай 1: $1\le k<r$.**

Простого $p$ среди первых $k$ простых чисел нет. Поэтому

$$
S_m(k)\equiv k\pmod p.
$$

Но $r=\pi(p)\le p$, следовательно, $k<r\le p$. Значит, $0<k<p$ и $p\nmid k$.

Таким образом, малые $k$ не могут быть контрпримерами: они вообще не являются кратными $p$.

**Случай 2: $k\ge r$.**

Среди первых $k$ простых чисел ровно одно равно $p$. Его $m$-я степень даёт остаток 0, остальные $k-1$ слагаемых дают остаток 1.

Следовательно,

$$
\boxed{S_m(k)\equiv k-1\pmod p}.
$$

Предположим теперь, что $p\mid k$. Тогда

$$
S_m(k)\equiv-1\pmod p.
$$

Поскольку $p\ge2$, остаток $-1$ не равен нулю по модулю $p$.

Следовательно, $p\nmid S_m(k)$, а тем более $k\nmid S_m(k)$.

Получили противоречие с условием $k\in A_m$. Теорема доказана. $\square$

### Применение к A111441

Для $m=2$ условие $p-1\mid2$ выполняется ровно при

$$
p\in\{2,3\}.
$$

Следовательно, любой член A111441, кроме 1, нечётен и не делится на 3.

В частности, числа вида

$$
k\equiv3\ \text{или}\ 9\pmod{12}
$$

обязательно кратны 3 и не могут принадлежать A111441. Исходная гипотеза доказана.

Более того, для любого положительного чётного $m$ выполняется $3-1\mid m$, поэтому тот же вывод верен для каждой последовательности с чётной степенью.

Для запрошенных степеней теорема даёт следующие исключения:

| Степень $m$ | Простые $p$, для которых $p-1\mid m$ |
| --- | --- |
| 2 | 2, 3 |
| 4 | 2, 3, 5 |
| 6 | 2, 3, 7 |
| 12 | 2, 3, 5, 7, 13 |

Это точно соответствует таблице OEIS Wiki.

**Особый случай $k=1$.** Поскольку $S_m(1)=2^m$ и $1\mid2^m$, число 1 принадлежит $A_m$ при любой положительной степени $m$. Противоречия нет: единица не делится ни на одно простое число.

## 3. Прямая вычислительная проверка (COMPUTED)

Проверка выполнена локально на Python с использованием решета Эратосфена и целочисленной арифметики без округлений.

Проверены все $1\le k\le10^6$ для квадратов и все $1\le k\le10^5$ для степеней $m=2,4,6,12$.

### Код Python

```python

from math import isqrt

N = 1_000_000
M = 100_000
LIMIT = 16_000_000  # 1,000,000th prime is 15,485,863
excluded = {
    2: (2, 3),
    4: (2, 3, 5),
    6: (2, 3, 7),
    12: (2, 3, 5, 7, 13),
}

# Generate the first N primes with the sieve of Eratosthenes.
sieve = bytearray(b'\x01') * (LIMIT + 1)
sieve[:2] = b'\x00\x00'
for p in range(2, isqrt(LIMIT) + 1):
    if sieve[p]:
        sieve[p * p::p] = b'\x00' * (
            (LIMIT - p * p) // p + 1
        )
primes = [p for p, flag in enumerate(sieve) if flag][:N]
assert len(primes) == N

sq_sum = 0
square_terms = []
sums = {m: 0 for m in excluded}
counts = {m: 0 for m in excluded}

for k, q in enumerate(primes, start=1):
    sq_sum += q * q
    if sq_sum % k == 0:
        square_terms.append(k)

    if k <= M:
        for m, forbidden in excluded.items():
            sums[m] += q ** m
            if sums[m] % k == 0:
                counts[m] += 1
                assert all(k % p != 0 for p in forbidden), (m, k)

known = [1, 19, 37, 455, 509, 575, 20597, 202717]
assert square_terms == known
assert all(k % 12 not in (3, 9) for k in square_terms)

print('A111441 terms for k <= 1000000:', square_terms)
print('Known OEIS terms below 1000000: MATCH')
print('Squares mod-12 conjecture, k <= 1000000: PASS')
for m, forbidden in excluded.items():
    print(
        f'm={m}, forbidden primes={forbidden}, '
        f'k <= 100000: PASS (terms={counts[m]})'
    )
```
