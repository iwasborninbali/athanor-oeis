# OEIS A007850 — Giuga Numbers and the Arithmetic Derivative

**Research report — 12 November 2026**

**Task:** Determine the status of Paolo P. Lava's 2009 conjecture that Giuga numbers are exactly the positive integers satisfying $n'=n+1$, where $n'$ denotes the arithmetic derivative.

**Overall finding:** The conjecture remains apparently open. One direction is proved, and a stronger characterization was published in 2012. I independently verified the characterization for every integer from 2 through 5,000,000. No counterexample was found.

## 1. Status and literature

OPEN — no proof or counterexample located

### Original conjecture

Paolo P. Lava, 16 November 2009, comment in [OEIS A007850](https://oeis.org/A007850):

> Conjecture: Giuga numbers are the solution of the differential equation n' = n + 1, where n' is the arithmetic derivative of n.

This is a mathematically well-posed conjecture over positive integers.

### Decisive published result

José María Grau and Antonio M. Oller-Marcén, **“Giuga Numbers and the Arithmetic Derivative,”** *Journal of Integer Sequences*, Volume 15 (2012), Article 12.4.1, Proposition 5, published 26 March 2012.

- [Journal publication](https://cs.uwaterloo.ca/journals/JIS/VOL15/Oller/oller5.html)
- [arXiv:1103.2298](https://arxiv.org/abs/1103.2298)
- [Full paper (PDF)](https://www.unioviedo.es/grau/ARTICULOS%20PUBLICADOS/articulo29.pdf)

**Known theorem (Proposition 5):**

For every integer $n>1$,

$$
\boxed{n\text{ is Giuga}\iff n'=an+1
\text{ for some integer }a\ge1.}
$$

The authors explicitly distinguish this theorem from Lava's stronger conjecture. Their abstract states:

> Although this fact does not refute Lava’s conjecture, it does suggest doubts about its veracity.



### Subsequent evidence

Jonathan Sondow, **8 January 2014**, OEIS A007850, observes:

> In fact, all known Giuga numbers n satisfy Sum_ 1/p = 1/n + 1.

The live OEIS entry retains both Lava's conjecture and Grau–Oller-Marcén's characterization. The OEIS Wiki's *Talk:Conjectures/List* also retains the original conjecture.

Eric W. Weisstein, *MathWorld*, “Giuga Number,” likewise reports that the known examples have reciprocal-sum difference 1, while Giuga numbers of higher order would require many prime factors.

## 2. Proof and strongest established partial result

### 2.1 Precise formulation

The arithmetic derivative is defined by

$$
1'=0,\qquad p'=1\quad(p\text{ prime}),
$$

and the Leibniz rule

$$
(ab)'=a'b+ab'.
$$

Consequently, if

$$
n=\prod_{i=1}^{r}p_i^{e_i},
$$

then

$$
n'=n\sum_{i=1}^{r}\frac{e_i}{p_i}.
$$

A Giuga number is a composite integer $n$ satisfying

$$
p\mid\left(\frac np-1\right)
$$

for every prime divisor $p\mid n$.

Every Giuga number is squarefree: if $p^2\mid n$, then $n/p\equiv0\pmod p$, contradicting the defining condition.

### 2.2 Known theorem: complete proof

**Claim (proved in Grau–Oller-Marcén, 2012):**

$$
n\text{ is Giuga}
\iff
n'=an+1\text{ for some }a\in\mathbb Z_{>0}.
$$

**Forward direction.**

Suppose $n$ is Giuga.

Since $n$ is squarefree, its arithmetic derivative is

$$
n'=\sum_{p\mid n}\frac np.
$$

Fix a prime $p\mid n$. For every other prime $q\mid n$, the integer $n/q$ is divisible by $p$. Hence

$$
n'\equiv\frac np\equiv1\pmod p.
$$

This holds for every prime divisor of $n$.

Because $n$ is squarefree, the Chinese remainder theorem gives

$$
n'\equiv1\pmod n.
$$

Thus $n'=an+1$ for some integer $a$.

Also $n'>1$, since $n$ is composite and its derivative is a sum of at least two positive integers. Therefore $a\ge1$.

**Reverse direction.**

Suppose

$$
n'=an+1,\qquad a\ge1.
$$

If $n$ were prime, then $n'=1$, impossible. The case $n=1$ is also impossible.

If a prime square $p^2$ divided $n$, the arithmetic-derivative formula would imply $p\mid n'$. But

$$
n'=an+1\equiv1\pmod p,
$$

a contradiction.

Therefore $n$ is squarefree and composite.

For any prime $p\mid n$,

$$
n'=\sum_{q\mid n}\frac nq
\equiv\frac np\pmod p.
$$

Since $n'=an+1$,

$$
\frac np\equiv1\pmod p.
$$

This is exactly Giuga's defining condition.

The equivalence is proved.

**Novelty:** None. This reproduces the known 2012 theorem using elementary modular arithmetic.

### 2.3 What remains open

For a Giuga number, define its *Giuga coefficient*

$$
a(n)=\frac{n'-1}{n}.
$$

Because Giuga numbers are squarefree,

$$
\boxed{
a(n)=\sum_{p\mid n}\frac1p-\frac1n
\in\mathbb Z_{>0}.
}
$$

Lava's conjecture is therefore equivalent to

$$
\boxed{\text{Every Giuga number has }a(n)=1.}
$$

A counterexample would be a Giuga number with $a(n)\ge2$.

This is the remaining unresolved implication.

### 2.4 Proven restriction on any counterexample

Let $\omega(n)$ denote the number of distinct prime divisors of $n$, and let $p_j$ denote the $j$-th prime.

**Claim (known type of bound, independently verified):** Every counterexample to Lava's conjecture must satisfy

$$
\boxed{\omega(n)\ge59.}
$$

**Proof.**

An exact rational calculation gives

$$
\sum_{j=1}^{58}\frac1{p_j}<2,
$$

where $p_{58}=271$.

If a Giuga number $n$ has at most 58 prime factors, then its reciprocals are bounded above by those of the first 58 primes:

$$
\begin{aligned}
a(n)
&=\sum_{p\mid n}\frac1p-\frac1n\\
&<\sum_{j=1}^{58}\frac1{p_j}\\
&<2.
\end{aligned}
$$

But $a(n)$ is a positive integer. Therefore

$$
a(n)=1,
$$

and consequently

$$
n'=n+1.
$$

Thus no counterexample can have 58 or fewer distinct prime factors.

The 2012 paper cites earlier literature for a related, stronger large-factor restriction; this elementary 58-factor argument is not claimed as new.

I ran a complete integer search over the indicated interval. The program calculates the arithmetic derivative using the Leibniz rule and checks Giuga's prime-divisibility condition separately.

### Reproducible Python program

```python

from array import array
from math import isqrt
from fractions import Fraction

N = 5_000_000

# Smallest prime factors; zero denotes a prime.
spf = array('I', [0]) * (N + 1)

for p in range(2, isqrt(N) + 1):
    if spf[p] == 0:
        for m in range(p*p, N+1, p):
            if spf[m] == 0:
                spf[m] = p

D = array('I', [0]) * (N + 1)

giugas = []
equation = []
higher = []
mismatches = []
non_squarefree_mod = 0

for n in range(2, N+1):
    p = spf[n] or n

    # Leibniz rule: (p*m)' = p*m' + m.
    D[n] = p * D[n//p] + n//p

    if p == n:
        continue  # n is prime

    x = n
    ok = True
    squarefree = True

    while x > 1:
        q = spf[x] or x

        if (n//q - 1) % q != 0:
            ok = False

        x //= q
        if x % q == 0:
            squarefree = False
            while x % q == 0:
                x //= q

    if ok:
        giugas.append(n)

    if D[n] == n + 1:
        equation.append(n)

    if D[n] > n+1 and (D[n]-1) % n == 0:
        higher.append((n, (D[n]-1)//n))

    if ok != ((D[n]-1) % n == 0):
        mismatches.append(n)

    if not squarefree and (D[n]-1) % n == 0:
        non_squarefree_mod += 1

print("Range: 2..5,000,000 (inclusive)")
print("Giuga numbers:", giugas)
print("Solutions n'=n+1:", equation)
print("Higher-order Giuga candidates (a>=2):", higher)
print("Giuga iff n'==1 (mod n), composite mismatches:",
      len(mismatches))
print("Non-squarefree composite n with n'==1 (mod n):",
      non_squarefree_mod)
print("Values (n, n', a):",
      [(n, D[n], (D[n]-1)//n) for n in giugas])

# Exact rational checks for the prime-factor bound.
first_59 = [x for x in range(2, 300) if spf[x] == 0]

r58 = sum((Fraction(1,p) for p in first_59[:58]),
          Fraction(0))
r59 = sum((Fraction(1,p) for p in first_59[:59]),
          Fraction(0))

print("prime_58:", first_59[57],
      "prime_59:", first_59[58])
print("sum_reciprocals_58_less_than_2:", r58 < 2)
print("sum_reciprocals_59_greater_than_2:", r59 > 2)
print("sum_reciprocals_58 approx:",
      format(float(r58), ".12f"))
print("sum_reciprocals_59 approx:",
      format(float(r59), ".12f"))
```
