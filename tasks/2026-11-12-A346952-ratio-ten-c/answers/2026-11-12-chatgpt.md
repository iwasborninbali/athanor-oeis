## 1. Status — PROVED (already known)

**Verdict: The conjecture in OEIS A346952 is true and was explicitly marked as proved in the OEIS entry on March 16, 2026. It is not an open problem.**

The statement is

$$
\boxed{\lim_{n\to\infty}\frac{a(n)}{a(n-1)}=10,}
$$

where $a(n)$ counts the $n$-digit positive integers expressible as $(10u+3)(10v+3)$, with $u,v\geq0$.

### Decisive existing sources

**Source 1 — Stefano Spezia, OEIS A346952, March 16, 2026.**

The entry retains the original conjecture but adds this explicit resolution:

> The conjecture is true since the sequence A346950 has positive asymptotic density (see Corollary 1 in Spezia link).

This is a direct statement of the result by the sequence's original author.

**Source 2 — Stefano Spezia, OEIS A346950, March 16, 2026.**

The underlying sequence consists of all positive integers representable as products of two integers ending in 3. Its entry states:

> The asymptotic density of this sequence is 1/10.

This supplies the density hypothesis used to resolve A346952.

**Source 3 — Stefano Spezia, *On the counting of k-digit terms in increasing sequences of positive integers*, author's mathematics website, published August 22, 2025; updated May 31, 2026.**

Corollary 1 establishes that if an increasing integer sequence has asymptotic density $\delta>0$, then its number $b_k$ of $k$-digit terms in base $B$ satisfies

$$
b_k\sim\delta(B-1)B^{k-1},
\qquad
\lim_{k\to\infty}\frac{b_k}{b_{k-1}}=B.
$$

Applying this with $B=10$ and $\delta=1/10$ gives the desired limit.

## 2. Proof — independent verification of the known result

Although the conjecture is already resolved, the density assertion can be justified with a short, self-contained argument using a classical theorem about primes in arithmetic progressions.

### Step 1. Characterize a sufficient condition for representability

Let

$$
S=\{(10u+3)(10v+3):u,v\in\mathbb Z_{\geq0}\}.
$$

Every element of $S$ is congruent to $9\pmod{10}$. Therefore,

$$
\#\{m\leq X:m\in S\}\leq\frac X{10}+O(1).
$$

**Lemma.** If $m\equiv9\pmod{10}$ has a prime divisor $p\equiv3\pmod{10}$, then $m\in S$.

**Proof.** Write $m=pq$. Because $p\equiv3\pmod{10}$, its multiplicative inverse modulo 10 is 7. Hence

$$
q\equiv9\cdot7\equiv3\pmod{10}.
$$

Thus both $p$ and $q$ are positive integers ending in 3, and $m=pq\in S$. $\square$

### Step 2. Show that the exceptions have density zero

Let $E(X)$ count integers $m\leq X$ satisfying $m\equiv9\pmod{10}$ but $m\notin S$.

By the lemma, such integers have **no prime divisor congruent to $3\pmod{10}$**.

Let $P$ be any finite set of primes congruent to 3 modulo 10. Inclusion–exclusion gives

$$
\#\{m\leq X:p\nmid m\text{ for all }p\in P\}
=
X\prod_{p\in P}\left(1-\frac1p\right)
+O(2^{|P|}).
$$

Consequently,

$$
\limsup_{X\to\infty}\frac{E(X)}X
\leq\prod_{p\in P}\left(1-\frac1p\right).
$$

The classical Mertens theorem for arithmetic progressions gives

$$
\sum_{\substack{p\leq Y\\p\equiv3\ (10)}}\frac1p
=\frac14\log\log Y+O(1).
$$

In particular, this reciprocal-prime sum diverges. L-functions and primes in progressions

Using $\log(1-t)\leq-t$ for $0<t<1$, we obtain

$$
\prod_{\substack{p\leq Y\\p\equiv3\ (10)}}
\left(1-\frac1p\right)
\longrightarrow0.
$$

Since $P$ may contain arbitrarily many primes from this progression,

$$
\limsup_{X\to\infty}\frac{E(X)}X=0.
$$

As $E(X)\geq0$, this proves

$$
\boxed{E(X)=o(X).}
$$

### Step 3. Obtain the density

Every integer in $S$ ends in 9, and all but $o(X)$ integers ending in 9 belong to $S$. Thus, writing

$$
N(X)=\#\{m\leq X:m\in S\},
$$

we have

$$
N(X)=\frac X{10}+o(X).
$$

Therefore,

$$
\boxed{\lim_{X\to\infty}\frac{N(X)}X=\frac1{10}.}
$$

This independently verifies the density stated in A346950.

### Step 4. Deduce the conjectured ratio

For $n\geq2$, the number of representable $n$-digit integers is exactly

$$
a(n)=N(10^n-1)-N(10^{n-1}-1).
$$

Applying the established asymptotic formula,

$$
\begin{aligned}
a(n)
&=\frac{10^n-10^{n-1}}{10}+o(10^n)\\
&=9\cdot10^{n-2}+o(10^n)\\
&=9\cdot10^{n-2}(1+o(1)).
\end{aligned}
$$

Hence

$$
\frac{a(n)}{a(n-1)}
=
10\frac{1+o(1)}{1+o(1)}
\longrightarrow10.
$$

$$
\boxed{\displaystyle\lim_{n\to\infty}\frac{a(n)}{a(n-1)}=10.}
$$

**Proof complete.**

**Status:** This is a rigorous verification of a previously recorded result, not a claim of priority. It uses only elementary modular arithmetic, inclusion–exclusion and the classical reciprocal-prime theorem for arithmetic progressions. No unresolved conjecture is required.

## 3. Computational check — executed

I independently enumerated products $pq<10^9$ with $p,q\equiv3\pmod{10}$, counting each distinct product once.

The following C++17 program implements the enumeration. It also checks the covering lemma for 18 primes congruent to 3 modulo 10.

```

#include <bits/stdc++.h>
using namespace std;

int main() {
    constexpr uint64_t LIM = 1000000000ULL;
    vector<uint8_t> seen(LIM / 10, 0);

    // Enumerate all products p*q < LIM,
    // with p <= q and p,q ending in 3.
    for (uint64_t p = 3; p*p < LIM; p += 10)
        for (uint64_t q = p; q*p < LIM; q += 10)
            seen[(p*q - 9) / 10] = 1;

    uint64_t count[10] = {}, slots[10] = {};
    uint64_t power = 10;
    int digits = 1;

    for (uint64_t i = 0; i < LIM/10; ++i) {
        uint64_t x = 10*i + 9;
        while (x >= power) {
            power *= 10;
            ++digits;
        }
        ++slots[digits];
        count[digits] += seen[i];
    }

    for (int n = 1; n <= 9; ++n)
        cout << n << ' ' << count[n] << ' '
             << slots[n]-count[n] << " / "
             << slots[n] << '\n';

    // Verify coverage for selected primes 3 mod 10.
    int primes[] = {
        3,13,23,43,53,73,83,103,113,
        163,173,193,223,233,263,283,293,313
    };

    uint64_t tested = 0, bad = 0;
    for (int p : primes) {
        for (uint64_t q = 3;
             (uint64_t)p*q < LIM; q += 10) {
            uint64_t x = (uint64_t)p*q;
            ++tested;
            if (!seen[(x-9)/10]) ++bad;
        }
    }

    cout << "small-prime coverage checks: "
         << tested << " (with repetitions); failures: "
         << bad << '\n';
}
```
