# 1. Status — open in general; verified through class number 3500 subject to published completeness claims

**As of 12 November 2026, I found no proof or counterexample to the full conjecture in OEIS A038552.** There is, however, substantial new progress in October–November 2026. In particular, a recently published classification permits the conjecture to be checked for **every class number $1\le n\le3500$**, provided its stated analytic assumption and computational completeness claims are accepted.

The relevant distinction is between a *complete classification of fields with bounded class number* and a *proof of the proposed property for every class number*.

### The precise conjecture

Let $h(D)$ be the class number of the imaginary quadratic field with negative fundamental discriminant $D$. For each positive integer $n$ represented by such a field, define

$$
M(n)=\max\{|D|:D<0\text{ fundamental},\ h(D)=n\}.
$$

Let $A(n)$ be OEIS A038552:

$$
A(n)=\max\{k:k>0\text{ squarefree},\
h(\mathbb Q(\sqrt{-k}))=n\}.
$$

The conjecture is

$$
\boxed{A(n)=M(n)\quad\text{for every represented }n.}
$$

The qualification “represented” avoids silently assuming that every positive integer occurs as an imaginary quadratic class number.

The OEIS entry, attributed in its present wording to Jianing Song (3 October 2022), states:

> “Conjecture: this is also the largest absolute value of negative fundamental discriminant d for class number n.”

Ralf Stephan also observed in OEIS on 7 July 2003 that the displayed terms are all $19\bmod24$. These are distinct statements: the congruence observation is stronger than what is needed for the proposed equality.

# 2. Proof of a general partial result, and the finite reduction

## 2.1 An exact reformulation

**Proved.** For squarefree $k>0$, the fundamental discriminant of $\mathbb Q(\sqrt{-k})$ is

$$
D_k=
\begin{cases}
-k,&k\equiv3\pmod4,\\
-4k,&\text{otherwise}.
\end{cases}
$$

Conversely, every negative fundamental discriminant $D$ corresponds to exactly one squarefree radicand,

$$
k(D)=
\begin{cases}
|D|,&D\text{ odd},\\
|D|/4,&D\text{ even}.
\end{cases}
$$

Therefore $k(D)\le |D|$, with equality exactly when $D$ is odd.

For a represented class number $n$,

$$
A(n)=\max_{h(D)=n}k(D),\qquad
M(n)=\max_{h(D)=n}|D|.
$$

It follows immediately that

$$
\boxed{
A(n)=M(n)
\iff
\text{the fundamental discriminant attaining }M(n)
\text{ is odd}.
}
\tag{1}
$$

**Proof.** If a maximizing $D$ is odd, its squarefree radicand is $k=|D|=M(n)$, hence $A(n)\ge M(n)$. The reverse inequality holds for every radicand.

If the maximizing $D$ is even, its radicand is $|D|/4<M(n)$, while every other discriminant has absolute value strictly below $M(n)$, hence every other radicand also does. Thus $A(n)<M(n)$. $\square$

This equivalence is elementary; it is not a new deep theorem.

## 2.2 The conjecture is true for every odd class number

**Proved, unconditionally, from classical genus theory.**

Let $D<0$ be fundamental, and let $t$ be the number of distinct prime divisors of $D$. Gauss's genus theory implies

$$
2^{t-1}\mid h(D).
$$

In particular, if $h(D)$ is odd, then $t=1$. This is the standard class-group 2-torsion consequence of genus theory.

The only *even* negative fundamental discriminants having a single distinct prime divisor are

$$
D=-4,\qquad D=-8.
$$

Both have class number 1.

Consequently:

- For any odd $n>1$, **every** negative fundamental discriminant of class number $n$ is odd.
- For $n=1$, the odd discriminant $D=-163$ has class number 1 and exceeds both even possibilities in absolute value.

Thus the maximizing discriminant is odd whenever $n$ is odd, and equation (1) proves

$$
\boxed{
A(n)=M(n)\quad\text{for every represented odd }n.
}
\tag{2}
$$

This result is not new: it is an immediate application of genus theory and the elementary class-number-one examples.

Therefore **the entire unresolved content of A038552 concerns even class numbers**.

## 2.3 A stronger finite conclusion for $1\le n\le3500$

**Computed from published data; mathematically conditional on completeness.**

I parsed Murphy's complete 3,500-row `range1_per_h.txt` file. Each row is

$$
n,\quad F(n),\quad M(n),\quad \min\{|D|:h(D)=n\},
$$

where $F(n)$ is the reported number of fields of class number $n$.

The result is striking:

$$
\boxed{M(n)\equiv19\pmod{24}\qquad(1\le n\le3500).}
\tag{3}
$$

There are **zero exceptions** in the published summary.

Since $19\bmod24$ is odd, equation (1) immediately gives

$$
\boxed{
A(n)=M(n)\qquad(1\le n\le3500),
}
\tag{4}
$$

**assuming Murphy's classification is complete and Kimura's analytic input holds as claimed**.

This is a stronger finite statement than the conjecture itself. Equation (3) extends Stephan's numerical $19\bmod24$ observation from the previously published small terms to a much larger reported complete classification.

## 3.2 Independent exact class-number calculation through $|D|\le100{,}000$

Here is the program I ran. It enumerates reduced primitive positive definite binary quadratic forms $(a,b,c)$, with

$$
D=b^2-4ac<0,\qquad |b|\le a\le c,
$$

counting the standard reduced representatives. Boundary representatives are counted only when $b\ge0$. Each counted representative contributes one proper equivalence class.

```python

from math import gcd, isqrt

B = 100_000
sf = bytearray(b'\x01') * (B + 1)
sf[0] = 0

for p in range(2, isqrt(B) + 1):
    if sf[p]:
        for j in range(p*p, B+1, p*p):
            sf[j] = 0

fund = bytearray(B + 1)
for d in range(3, B + 1):
    if d % 4 == 3:
        fund[d] = sf[d]
    elif d % 4 == 0 and (d//4) % 4 in (1, 2):
        fund[d] = sf[d//4]

h = [0] * (B + 1)
for a in range(1, isqrt(B//3) + 1):
    for b in range(-a+1, a+1):
        for c in range(a, (B+b*b)//(4*a) + 1):
            if c == a and b < 0:
                continue
            d = 4*a*c-b*b
            if fund[d] and gcd(a, gcd(abs(b), c)) == 1:
                h[d] += 1

maxima = {}
for d in range(3, B + 1):
    if h[d]:
        maxima[h[d]] = d

expected = [
    163,427,907,1555,2683,3763,5923,6307,
    10627,13843,15667,17803,20563,30067,
    34483,31243,37123,48427,38707,58507,
    61483,85507,90787
]

print("B =", B)
print("fundamental_discriminants =", sum(fund))
print("OEIS_match_n_1_to_23 =",
      [maxima.get(n) for n in range(1,24)] == expected)
print("even_maxima_n_1_to_23 =",
      [(n,maxima[n]) for n in range(1,24)
       if maxima[n] % 2 == 0])
print("n_1_to_23_maxima_all_19_mod_24 =",
      all(maxima[n] % 24 == 19 for n in range(1,24)))
print("h(-3),h(-4),h(-8),h(-163),h(-427) =",
      [h[d] for d in (3,4,8,163,427)])
```

Exact output:

```

fundamental_discriminants = 30392
OEIS_match_n_1_to_23 = True
even_maxima_n_1_to_23 = []
n_1_to_23_maxima_all_19_mod_24 = True
h(-3),h(-4),h(-8),h(-163),h(-427) = [1, 1, 1, 1, 2]
```

This verifies the 23 indicated maxima **within the exhaustive search range $|D|\le100{,}000$**, not their global maximality by itself. The global assertion for these indices follows separately from the established Watkins classification.

The two computational checks are complementary: the small-range calculation is independent of the published table values, while the 3,500-row scan directly tests the strongest presently accessible complete-list claim. Neither should be mistaken for a fresh independent proof of Murphy's overall classification.
