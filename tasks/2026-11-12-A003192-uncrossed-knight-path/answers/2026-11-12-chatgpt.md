## 1. Status — PROVED (2010)

**Verdict: The conjecture is already settled.** Donald E. Knuth established in 2010 that the maximum length of an uncrossed knight's path on a $9\times9$ board is exactly 47 moves, using zero-suppressed binary decision diagrams (ZDDs).

The decisive primary-source statement is Knuth's own comment in OEIS A003192, dated June 24, 2010:

> I used ZDD techniques to show that a(9)=47. (This is the longest uncrossed knight's path on a 9 X 9 board; thus I confirmed the conjecture that the paths of length 47, found by hand long ago, are indeed optimum.) — Don Knuth, Jun 24 2010.

This is an explicit claim of completed computational proof, not a conjecture still awaiting resolution.

**Bibliographic identification**

- Donald E. Knuth (2010), *Long and skinny knight's tours*, in *Selected Papers on Fun and Games*, CSLI Lecture Notes, vol. 192, CSLI Publications, Stanford, California. Listed in A003192's references.
- Donald E. Knuth, *Knight's Tours Writ Large*, Stanford University website, § “Level 4: Noncrossing cycles.” Knuth independently describes how ZDD technology made optimal computations possible and identifies Chapter 40 of *Selected Papers on Fun and Games* as the detailed account of the noncrossing-cycle computations. This is corroborating methodological evidence, not by itself a proof of the open-path value 47.
- OEIS A157416, the companion sequence for longest uncrossed *cycles*, separately records Knuth's ZDD computations. Its values differ from A003192, so the two problems must not be confused.

The relevant historical distinction is between finding a 47-move path (a lower bound) and proving that no path of 48 or more moves exists (an upper bound). Knuth explicitly states that his computation established the latter.

The problem of determining $a(n)$ for general $n$ remains distinct from this settled finite case. The published sequence A003192 currently lists exact values through $n=9$; a general formula is not established by the cited result.

## 2. Mathematical formulation and proof status

**Precise formulation.**

Let

$$
V_n=\{(x,y)\in\mathbb Z^2:0\le x,y<n\}.
$$

An uncrossed knight's path is a sequence of distinct vertices

$$
P=(v_0,v_1,\ldots,v_k)
$$

such that:

1. Every consecutive pair differs by $(\pm1,\pm2)$ or $(\pm2,\pm1)$.
2. The straight-line segments $[v_{i-1},v_i]$ do not intersect except at shared endpoints of consecutive segments.
3. Its length is $k$, the number of moves, not the number of visited squares.

Define

$$
a(n)=\max_P k.
$$

The particular claim established by Knuth is

$$
\boxed{a(9)=47.}
$$

Equivalently, there exists a legal 47-move path on a $9\times9$ board, and no legal path has 48 or more moves.

Yarbrough's original formulation also permits a final move returning to the starting square, producing a closed cycle. Such cycles are separately recorded in OEIS A157416. For the present $9\times9$ problem this distinction does not alter the maximum, because the known maximum cycle length is 42.

**Proof status: known computational proof, not reproduced here.**

Knuth's ZDD computation is the established resolution. I found no reason to replace it with a speculative alternative proof.

Consequently, no new mathematical proof or counterexample is claimed in this report. The independent computation below provides a smaller-scale check of the definitions and known values, not an independent certificate for the $9\times9$ upper bound.

## 3. Independent computational check

I implemented an exhaustive C++17 depth-first search.

The program constructs the knight-move graph, precomputes intersecting edge pairs using exact integer orientation tests, and explores legal self-avoiding paths. Two safe optimizations reduce the search:

- Rotations and reflections allow only one representative starting square from each symmetry orbit.
- A graph-reachability upper bound prunes a search branch when the remaining reachable squares cannot improve the best result.

The second bound is valid because any continuation must remain inside the component reachable from the current endpoint after removing visited squares and geometrically blocked moves.

Complete source code

```

#include <bits/stdc++.h>
using namespace std;

struct Edge { int a,b; };
int n, optimum;
unsigned long long nodes;
vector<Edge> edges;
vector<vector<pair<int,int>>> adj;
vector<vector<int>> crosses;
vector<int> blocked;

int orient(int a,int b,int c) {
  int ax=a%n, ay=a/n, bx=b%n, by=b/n;
  int cx=c%n, cy=c/n;
  return (bx-ax)*(cy-ay)-(by-ay)*(cx-ax);
}

bool crossing(Edge p,Edge q) {
  return orient(p.a,p.b,q.a)*orient(p.a,p.b,q.b)<0 &&
         orient(q.a,q.b,p.a)*orient(q.a,q.b,p.b)<0;
}

int reachable(int u,uint64_t visited) {
  uint64_t seen=uint64_t(1)<<u;
  int queue[64],lo=0,hi=0;
  queue[hi++]=u;
  while(lo<hi)
    for(auto [v,e]:adj[queue[lo++]])
      if(!blocked[e] && !(visited>>v&1) &&
         !(seen>>v&1)) {
        seen|=uint64_t(1)<<v;
        queue[hi++]=v;
      }
  return hi;
}

void search(int u,uint64_t visited,int length) {
  ++nodes;
  optimum=max(optimum,length);
  if(length+n*n-__builtin_popcountll(visited)<=optimum)
    return;
  if(length+reachable(u,visited)-1<=optimum)
    return;

  for(auto [v,e]:adj[u])
    if(!(visited>>v&1) && !blocked[e]) {
      for(int f:crosses[e]) ++blocked[f];
      search(v,visited|(uint64_t(1)<<v),length+1);
      for(int f:crosses[e]) --blocked[f];
    }
}

int main() {
  for(n=1;n<=7;++n) {
    adj.assign(n*n,{});
    edges.clear();

    for(int a=0;a<n*n;++a)
      for(int b=a+1;b<n*n;++b) {
        int dx=abs(a%n-b%n),dy=abs(a/n-b/n);
        if((dx==1&&dy==2)||(dx==2&&dy==1)) {
          int e=edges.size();
          edges.push_back({a,b});
          adj[a].push_back({b,e});
          adj[b].push_back({a,e});
        }
      }

    crosses.assign(edges.size(),{});
    for(int e=0;e<(int)edges.size();++e)
      for(int f=0;f<e;++f)
        if(crossing(edges[e],edges[f])) {
          crosses[e].push_back(f);
          crosses[f].push_back(e);
        }

    blocked.assign(edges.size(),0);
    optimum=0;
    nodes=0;

    for(int a=0;a<n*n;++a) {
      int x=a%n,y=a/n;
      int syms[8][2]={
        {x,y},{n-1-x,y},{x,n-1-y},
        {n-1-x,n-1-y},{y,x},{n-1-y,x},
        {y,n-1-x},{n-1-y,n-1-x}
      };
      int smallest=a;
      for(auto &p:syms)
        smallest=min(smallest,p[1]*n+p[0]);
      if(a==smallest)
        search(a,uint64_t(1)<<a,0);
    }

    cout<<"n="<<n<<" a(n)="<<optimum
        <<" nodes="<<nodes<<'\n';
  }
}
```
