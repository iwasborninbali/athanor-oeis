# 1. Status: OEIS A078437

$$
C=\sum_{k=1}^{\infty}\frac{(-1)^{k-1}}{p_k}

# 2. Proof attempt and rigorous partial result

## 2.1 Convergence and exact bounds

**Proved (standard result).**

Write

$$
S_N=\sum_{k=1}^{N}\frac{(-1)^{k-1}}{p_k}.
$$

Because the primes increase strictly and tend to infinity,

$$
\frac1{p_1}>\frac1{p_2}>\cdots>0,
\qquad
\lim_{k\to\infty}\frac1{p_k}=0.
$$

The alternating-series theorem therefore proves that $C$ exists and, for every $m\geq1$,

$$
\boxed{S_{2m}<C<S_{2m+1}.}
\tag{1}
$$

The width of this rigorous enclosure is exactly

$$
S_{2m+1}-S_{2m}=\frac1{p_{2m+1}}.
\tag{2}
$$

These inequalities are strict because the series has infinitely many nonzero terms.

They can also be checked directly: the even partial sums increase, since

$$
S_{2m+2}-S_{2m}
=\frac1{p_{2m+1}}-\frac1{p_{2m+2}}>0,
$$

while the odd partial sums decrease, since

$$
S_{2m+3}-S_{2m+1}
=-\frac1{p_{2m+2}}+\frac1{p_{2m+3}}<0.
$$

Thus (1) gives a completely checkable certificate for any decimal digit whenever both endpoints lie in the same decimal-digit interval.

## 2.2 Why smoothing is not a proof

**Known numerical method; no certified tail estimate found.**

The entry uses

$$
h(k)=\frac{S_{k-2}+2S_{k-1}+S_k}{4}.
$$

For even $k$, algebra gives

$$
h(k)=S_k+\frac14
\left(\frac3{p_k}-\frac1{p_{k-1}}\right).
\tag{3}
$$

The smoothed values converge to $C$, because each constituent partial sum converges to $C$.

However, rapid apparent convergence of $h(2^m)$ does not imply an error estimate such as

$$
|h(2^m)-C|<10^{-19}.
$$

Indeed, from (1) and (3), we obtain only the guaranteed bounds

$$
-\frac14\left(\frac3{p_k}-\frac1{p_{k-1}}\right)
<C-h(k)
<
\frac1{p_{k+1}}
-\frac14\left(\frac3{p_k}-\frac1{p_{k-1}}\right)
\tag{4}
$$

for even $k$.

The derivation uses only the alternating-series remainder theorem; no assumption about statistical regularity of prime gaps is made.

These inequalities do not establish the conjectured digits from the reported smoothed values. Obtaining those digits rigorously would require substantially sharper error control or a sufficiently large direct summation certificate.

**Partial result:** The convergence, alternating bounds, and explicit enclosure (4) are proved. They do not resolve $a(14),\ldots,a(18)$. No new theorem or reduction to a named open problem has been established.

# 3. Computational verification

**Computed and rigorously bounded:** I evaluated the first **20,000,000 prime terms**, using a sieve and integer-only fixed-point arithmetic.

Rather than trusting floating-point rounding, the program constructs an interval guaranteed to contain $C$.

## 3.1 Certified arithmetic

Set

$$
Q=10^{26},\qquad N=20\,000\,000
$$

and calculate the integer

$$
T=\sum_{j=1}^{N}(-1)^{j-1}
\left\lfloor\frac{Q}{p_j}\right\rfloor.
$$

Each division introduces an error smaller than one unit in the scaled representation.

Since $N$ is even, there are $N/2$ positive and $N/2$ negative terms. Therefore

$$
\frac{T-N/2}{Q}\leq S_N
\leq\frac{T+N/2}{Q}.
$$

Applying the alternating-series remainder bound gives the certified enclosure

$$
\boxed{
\frac{T-N/2}{Q}
<
C
<
\frac{T+N/2+\lceil Q/p_{N+1}\rceil}{Q}.
}
\tag{5}
$$

All quantities in (5) are integers or exact rational numbers. No floating-point assumptions are needed.

## 3.2 Reproducible program

The following C++17 program was compiled with `g++ -O3 -std=c++17` and executed.

```

#include <cmath>
#include <cstdint>
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using i128 = __int128_t;

string show(i128 x, i128 scale) {
    string s; bool neg=x<0; if(neg) x=-x;
    i128 whole=x/scale; x%=scale;
    do {s=char('0'+whole%10)+s;whole/=10;} while(whole);
    string f(26,'0');
    for(int i=25;i>=0;--i){f[i]=char('0'+x%10);x/=10;}
    return (neg?"-":"")+s+"."+f;
}

int main() {
    constexpr int N=20000000, LIMIT=400000000;
    vector<uint8_t> composite((LIMIT+1)/2, 0);
    for (int p=3; 1LL*p*p<=LIMIT; p+=2)
        if (!composite[p/2])
            for(long long q=1LL*p*p;q<=LIMIT;q+=2LL*p)
                composite[q/2]=1;

    i128 Q=1; for(int i=0;i<26;i++)Q*=10;
    i128 scaled=0; int j=0, last=0, next=0;
    auto take=[&](int p) {
        ++j;
        if(j<=N) {
            scaled+=(j%2?1:-1)*(Q/p);
            last=p;
        } else if(j==N+1) next=p;
    };
    take(2);
    for(int p=3;p<=LIMIT&&j<=N;p+=2)
        if(!composite[p/2]) take(p);

    i128 lo=scaled-N/2;
    i128 hi=scaled+N/2+(Q+next-1)/next;
    cout<<"N="<<N<<" p_N="<<last
        <<" p_(N+1)="<<next<<"\n";
    string a=show(lo,Q), b=show(hi,Q);
    cout<<"lower="<<a<<"\n";
    cout<<"upper="<<b<<"\n";
    size_t common=0;
    while(common<a.size() && a[common]==b[common])
        ++common;
    cout<<"common_prefix="<<a.substr(0,common)<<"\n";
}
```
