# OEIS A051783 — Valluri’s primality criterion

**Research report · 12 November 2026**

## 1. Status and literature search

**Verdict: Apparently open.** I found no published proof or counterexample to Valluri’s conjecture. The forward implication is a theorem; the converse remains unestablished in the sources checked.

The precise conjecture is, for every integer $k\geq0$, with $N=3^k+2$,

$$
\boxed{N\text{ is prime}\iff 2^{(N-1)/2}\equiv-1\pmod N.}
$$

### Primary source

Maheswara Rao Valluri, comment dated **1 June 2020**, in N. J. A. Sloane et al., *The On-Line Encyclopedia of Integer Sequences*, entry [A051783](https://oeis.org/A051783):

> Conjecture: The number n = 3^k + 2 is prime if and only if 2^((n-1)/2) == -1 (mod n).

N. J. A. Sloane added a clarification on **7 September 2020** emphasizing that the statement is bidirectional and cannot be deduced from Fermat’s little theorem alone. The entry continued to label it a conjecture in the September 2026 version examined.

## 2. Proof and partial results

### Theorem 1 — Forward implication

**Status: PROVED (classical Euler criterion).**

For every integer $k\geq0$,

$$
3^k+2\text{ prime}
\implies
2^{(3^k+1)/2}\equiv-1\pmod{3^k+2}.
$$

**Proof.**

Set $N=3^k+2$. Since

$$
3^{2r}\equiv1\pmod8,\qquad
3^{2r+1}\equiv3\pmod8,
$$

we have

$$
N\equiv
\begin{cases}
3\pmod8,&k\text{ even},\\
5\pmod8,&k\text{ odd}.
\end{cases}
$$

Thus, whenever $N$ is prime, the supplementary law of quadratic reciprocity gives

$$
\left(\frac2N\right)
=(-1)^{(N^2-1)/8}=-1.
$$

Euler’s criterion then yields

$$
2^{(N-1)/2}\equiv
\left(\frac2N\right)
\equiv-1\pmod N.
$$

This includes $k=0$, for which $N=3$.

$\square$

### Theorem 2 — Equivalence to a base-2 strong probable-prime test

**Status: PROVED (deduction from standard pseudoprimality theory).**

For every $k\geq0$, the proposed congruence holds if and only if $N=3^k+2$ passes the base-2 Miller–Rabin strong probable-prime test.

**Proof.**

As above, $N\equiv3$ or $5\pmod8$, so its Jacobi symbol satisfies

$$
\left(\frac2N\right)=-1.
$$

Write $N-1=2^s d$, with $d$ odd. We have $s=1$ when $N\equiv3\pmod8$, and $s=2$ when $N\equiv5\pmod8$.

If $s=1$, the strong test accepts precisely when $2^d\equiv1$ or $-1\pmod N$. The first possibility is impossible: applying the Jacobi symbol would give

$$
-1=\left(\frac2N\right)^d
=\left(\frac1N\right)=1.
$$

Consequently, acceptance is equivalent to $2^d\equiv-1\pmod N$, exactly Valluri’s congruence.

If $s=2$, the strong test accepts precisely when

$$
2^d\equiv1,\quad 2^d\equiv-1,
\quad\text{or}\quad2^{2d}\equiv-1\pmod N.
$$

The first possibility is excluded as before. The second is also impossible, since $N\equiv5\pmod8$ implies

$$
\left(\frac{-1}N\right)=1,
$$

whereas $2^d\equiv-1\pmod N$ would imply

$$
\left(\frac{-1}N\right)
=\left(\frac2N\right)^d=-1.
$$

Hence acceptance is equivalent to $2^{2d}\equiv-1\pmod N$, again Valluri’s congruence.

$\square$

**Consequence.** Valluri’s conjecture can be restated exactly as:

$$
\boxed{\text{There is no base-2 strong pseudoprime of the form }3^k+2,\ k\geq0.}
$$

This is a useful characterization, but it does not settle the conjecture. Strong pseudoprimes to base 2 are known to exist in general.

### Theorem 3 — An infinite family satisfying the conjecture's composite case

**Status: PROVED; the underlying divisibility restriction is already known.**

For every integer $t\geq0$, take $k=6t+5$. Then $3^k+2$ is composite and fails Valluri’s congruence.

**Proof.**

Since $3$ has multiplicative order $6$ modulo $7$,

$$
3^{6t+5}\equiv3^5\equiv5\pmod7.
$$

Therefore,

$$
3^k+2\equiv0\pmod7.
$$

Because $k\geq5$, the integer $N=3^k+2$ is greater than $7$, and is composite.

Now put $m=(3^k+1)/2$. For every $k\geq1$,

$$
3^k\equiv3\pmod6
\quad\implies\quad m\equiv2\pmod3.
$$

Since $2^3\equiv1\pmod7$,

$$
2^m\equiv2^2\equiv4\pmod7.
$$

But $-1\equiv6\pmod7$. Hence

$$
2^m\not\equiv-1\pmod7,
$$

and therefore the required congruence also fails modulo $N$.

$\square$

The divisibility by $7$ for this residue class is already represented in the 2010 comments on A134753. Accordingly, this is not claimed as a novel result.

## 3. Computational verification

**Status: COMPUTED.**

I carried out two checks: a deterministic primality comparison for $0\leq k\leq40$, and a larger congruence search using GMP for $0\leq k\leq3000$.

### Reproducible GMP program

The following C program computes the modular exponent exactly, checks passing values with GMP's probable-prime function, and verifies the modulus-7 lemma on the stated range.

```
#include <gmp.h>
#include <stdio.h>

int main(void) {
    mpz_t a,n,e,r,t,two;
    mpz_inits(a,n,e,r,t,two,NULL);
    mpz_set_ui(a,1);
    mpz_set_ui(two,2);

    int pass=0, composite=0, probable=0, lemma_bad=0;

    puts("range: 0 <= k <= 3000");
    printf("criterion passes:");

    for (int k=0; k<=3000; ++k) {
        mpz_add_ui(n,a,2);
        mpz_sub_ui(t,n,1);
        mpz_fdiv_q_2exp(e,t,1);
        mpz_powm(r,two,e,n);

        if (k%6==5 &&
            (!mpz_divisible_ui_p(n,7) ||
             mpz_fdiv_ui(r,7)!=4))
            ++lemma_bad;

        if (mpz_cmp(r,t)==0) {
            printf(" %d",k);
            ++pass;
            int c=mpz_probab_prime_p(n,25);
            composite+=(c==0);
            probable+=(c==1);
        }
        mpz_mul_ui(a,a,3);
    }

    printf("\ncriterion pass count: %d\n",pass);
    printf("GMP definitely composite among passes: %d\n",
           composite);
    printf("GMP probable (not certified) among passes: %d\n",
           probable);
    printf("mod-7 lemma failures: %d\n",lemma_bad);

    mpz_clears(a,n,e,r,t,two,NULL);
    return 0;
}
```
