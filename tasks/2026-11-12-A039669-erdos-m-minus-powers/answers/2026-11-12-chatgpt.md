# 1. Status — OEIS A039669

**Research date:** 12 November 2026 **Verdict:** The intended Erdős conjecture remains **OPEN**. There is, however, a minor logical defect in the literal OEIS definition.

## 1.1 Precise statement

Define, for integers $m\ge3$,

$$
P(m)\iff
\forall k\in\mathbb Z_{\ge1},\quad
2^k<m\Longrightarrow m-2^k\text{ is prime}.
$$

The conjecture is

$$
\boxed{\{m\ge3:P(m)\}=\{4,7,15,21,45,75,105\}.}
$$

The seven displayed integers are verified solutions. Whether any $m>105$ satisfies $P(m)$ is unknown.

**Logical qualification.** The OEIS definition says merely “positive numbers $m$.” Taken literally, $m=1$ and $m=2$ also satisfy the condition, because there is no positive $k$ with $2^k<m$. Therefore the unqualified statement that *only* the seven displayed positive integers satisfy the condition is false.

The mathematically intended conjecture excludes these vacuous cases by requiring $m\ge3$. The discrepancy between nine and seven solutions below 20,000, discussed in the OEIS comments by Michel Marcus (2013) and Robert Israel (2015), is consistent with this distinction.

This boundary issue does **not** resolve the intended open problem.

**R. C. Vaughan (1973).** *Some applications of Montgomery's sieve*, *Journal of Number Theory* 5(1), 64–79. DOI: `10.1016/0022-314X(73)90059-0`.

Vaughan proved a quantitative upper bound. Writing

$$
E(N)=\#\{3\le m\le N:P(m)\},
$$

the bound is

$$
E(N)<
N\exp\left(
-c\frac{\log\log\log N}{\log\log N}\log N
\right)
$$

for some positive constant $c$ and sufficiently large $N$.

In particular,

$$
\boxed{E(N)=o(N).}
$$

This establishes zero asymptotic density, **not finiteness**. The bound is also discussed in Christian Elsholtz, *Upper bounds for prime $k$-tuples of size $\log N$ and oscillations*, *Archiv der Mathematik* 82 (2004), 33–39.

# 2. Proof attempt and rigorous partial results

The following deductions are elementary. The key primitive-root lemma is **known**, appearing in Uchiyama–Yorinaga (1977), pp. 132–133; it is reproduced here for checkability, not claimed as a discovery.

## 2.1 Parity restriction

**Proposition 1 (proved).** If $P(m)$ and $m>4$, then $m$ is odd.

**Proof.** If $m>4$ is even, then $m-2$ is an even integer greater than 2, hence composite. But $2<m$, so $P(m)$ requires $m-2$ to be prime. Contradiction. $\square$

Thus 4 is the only even solution.

## 2.2 Divisibility by 3 and 5

**Proposition 2 (proved).** Every solution $m>21$ is divisible by 15.

**Proof.**

First, suppose $m>7$ and $3\nmid m$.

If $m\equiv2\pmod3$, then $m-2$ is divisible by 3. Since it must be prime, $m-2=3$, giving $m=5$, a contradiction.

If $m\equiv1\pmod3$, then $m-4$ is divisible by 3. Again primality forces $m-4=3$, giving $m=7$, a contradiction.

Consequently,

$$
P(m),\ m>7\quad\Longrightarrow\quad3\mid m.
$$

Next, the powers

$$
2,\ 2^2,\ 2^3,\ 2^4
$$

have residues $2,4,3,1\pmod5$, covering all nonzero residue classes.

Suppose $m>21$ and $5\nmid m$. Then for some $1\le k\le4$,

$$
m\equiv2^k\pmod5.
$$

Thus $5\mid m-2^k$. But

$$
m-2^k\ge m-16>5,
$$

so the difference is composite, contradicting $P(m)$.

Hence $5\mid m$. Combining both conclusions gives

$$
\boxed{P(m),\ m>21\Longrightarrow15\mid m.}
$$

$\square$

## 2.3 Primitive-root obstruction

**Proposition 3 (proved; previously known).** Let $q$ be an odd prime for which 2 is a primitive root modulo $q$. If

$$
P(m)\quad\text{and}\quad m>2^{q-1}+q,
$$

then $q\mid m$.

**Proof.**

Suppose $q\nmid m$.

Since 2 is a primitive root modulo $q$, the residues

$$
2^1,2^2,\ldots,2^{q-1}\pmod q
$$

run through every nonzero residue class.

Therefore some $1\le k\le q-1$ satisfies

$$
m\equiv2^k\pmod q.
$$

It follows that

$$
q\mid m-2^k.
$$

Moreover,

$$
m-2^k\ge m-2^{q-1}>q.
$$

The positive integer $m-2^k$ is therefore a proper multiple of $q$ and cannot be prime.

This contradicts $P(m)$. Hence $q\mid m$. $\square$

The strict threshold is important: without it, the divisible difference might equal $q$, which is prime.

The result immediately gives the following necessary divisibilities.

| Range of a hypothetical solution | Required divisor |
| --- | --- |
| $m>7$ | 3 |
| $m>21$ | $3\cdot5=15$ |
| $m>1035$ | $3\cdot5\cdot11=165$ |
| $m>4109$ | $3\cdot5\cdot11\cdot13=2145$ |
| $m>262163$ | $3\cdot5\cdot11\cdot13\cdot19=40755$ |

These thresholds follow because 2 has multiplicative orders $2,4,10,12,18$ modulo $3,5,11,13,19$, respectively.

For instance, any hypothetical solution larger than 262163 must be an odd multiple of 40755.

This is a strong sieve restriction, but it does not eliminate every possible larger multiple. Iterating such restrictions is essentially the established critical-prime exclusion method.

## 2.4 Reduction to another open problem

Let

$$
f(m)=\#\{k\ge0:m-2^k\text{ is prime}\}.
$$

Erdős problem [#236](https://www.erdosproblems.com/236) asks whether

$$
f(m)=o(\log m).
$$

It is also listed as open. Problems

If $P(m)$ holds, then every exponent

$$
1\le k\le\lfloor\log_2(m-1)\rfloor
$$

contributes to $f(m)$. Thus

$$
f(m)\ge\lfloor\log_2(m-1)\rfloor
=\frac{\log m}{\log2}+O(1).
$$

Consequently, along any unbounded sequence of solutions,

$$
\liminf\frac{f(m)}{\log m}\ge\frac1{\log2}>0.
$$

Therefore:

$$
\boxed{
f(m)=o(\log m)
\quad\Longrightarrow\quad
\text{only finitely many }m\text{ satisfy }P(m).
}
$$

This is a rigorous conditional reduction to the stronger open conjecture #236.

It is **not an equivalence**. Even a proof of #236 would only establish eventual nonexistence; without an explicit bound and finite verification, it would not prove that 105 is the largest solution.

There is also a necessary connection with twin primes: for every solution $m>4$, the numbers $m-4$ and $m-2$ are both prime. Thus infinitely many solutions of $P(m)$ would imply infinitely many twin-prime pairs. The converse does not follow.

**Outcome of the proof attempt:** These arguments prove modular restrictions and a conditional finiteness implication. They do not prove the seven-term conjecture or produce a counterexample.

# 3. Computational check

## 3.1 Method

I ran a deterministic Python 3 program that:

1. Generates all primes through $10^7$ using the Sieve of Eratosthenes.
2. Checks each potentially eligible $m$, using Proposition 1 to skip even $m>4$.
3. Tests every power $2^k<m$, without floating-point exponent calculations.
4. Verifies multiplicative orders of 2 for six selected primes and checks that all discovered solutions satisfy Proposition 3.

The primality sieve uses exact integer arithmetic; no probabilistic primality tests are involved.

## 3.2 Executed program

```python

from math import isqrt

B = 10_000_000

prime = bytearray(b'\x01') * (B + 1)
prime[0:2] = b'\x00\x00'

for d in range(2, isqrt(B) + 1):
    if prime[d]:
        prime[d*d:B+1:d] = (
            b'\x00' * ((B-d*d)//d + 1)
        )

def good(n):
    t = 2
    while t < n:
        if not prime[n-t]:
            return False
        t <<= 1
    return True

solutions = [
    n for n in range(3, B+1)
    if (n == 4 or n % 2) and good(n)
]

def primitive_root_two(p):
    seen = set()
    a = 2 % p
    while a not in seen:
        seen.add(a)
        a = a*2 % p
    return len(seen) == p-1

critical = [
    p for p in (3, 5, 11, 13, 19, 29)
    if prime[p] and primitive_root_two(p)
]

thresholds = [
    (p, 2**(p-1) + p) for p in critical
]

assert solutions == [4, 7, 15, 21, 45, 75, 105]
assert all(
    m % p == 0
    for m in solutions
    for p, threshold in thresholds
    if m > threshold
)

print(f"range: 3..{B} inclusive")
print("solutions:", solutions)
print("primitive-root primes:", critical)
print("forcing thresholds (p, 2^(p-1)+p):", thresholds)
print("all solutions satisfy the forcing lemma: True")
```
