## 1. Status and prior art

### Statement and indexing

OEIS [A333650](https://oeis.org/A333650), created by Peter Kagey on March 31, 2020, defines $T(n,k)$ as the number of domino towers with $n$ bricks and exactly $k$ levels.

The entry states:

> Conjecture: For n > 1, T(n,2) = A000071(n+2).

As of the investigation date, this remains labeled a conjecture in the entry.

OEIS [A000071](https://oeis.org/A000071) defines

$$
\mathrm{A000071}(m)=F_m-1,
$$

where $F_0=0$, $F_1=1$, and $F_{m+2}=F_{m+1}+F_m$. Its offset is 1. Therefore the precise conjecture is

$$
\boxed{T(n,2)=F_{n+2}-1\qquad(n\ge2).}
$$

## 2. Proof

**Theorem.** For every integer $n\ge2$, the number of domino towers with $n$ bricks and exactly two levels is

$$
T(n,2)=F_{n+2}-1.
$$

### Lemma: towers with a fixed base

Fix a base containing $b\ge1$ contiguous horizontal bricks.

Scale coordinates so that each brick has length 2. The base occupies the interval $[0,2b]$, partitioned into $b$ consecutive bricks.

Since the next level is horizontally offset by half a brick, its possible brick positions have left endpoints

$$
-1,\ 1,\ 3,\ \ldots,\ 2b-1.
$$

There are exactly $b+1$ such positions.

The first and last have half their lengths supported by the base; each interior position is fully supported. Positions farther left or right have insufficient support.

Distinct positions are nonoverlapping. The definition allows gaps in upper levels and does not require overall stability.

Consequently, **every subset of these $b+1$ positions determines a valid second level**, and every valid second level arises uniquely this way.

If the upper level contains exactly $t\ge1$ bricks, the number of towers is therefore

$$
\boxed{N(b,t)=\binom{b+1}{t}.}
$$

This proves the lemma.

### Counting by total bricks

A two-level tower with $n$ bricks satisfies

$$
n=b+t.
$$

Thus $b=n-t$. The restrictions $t\ge1$ and $t\le b+1$ imply

$$
1\le t\le\left\lfloor\frac{n+1}{2}\right\rfloor.
$$

Summing over all possible upper-level sizes gives the exact enumeration

$$
\boxed{
T(n,2)=
\sum_{t=1}^{\lfloor(n+1)/2\rfloor}
\binom{n+1-t}{t}.
}
\tag{1}
$$

### Bijection to Fibonacci tilings

Consider tilings of a strip of length $n+1$ using tiles of lengths 1 and 2, with at least one tile of length 2.

For a tower with base width $b$, read its $b+1$ possible second-level positions from left to right:

- If a position is occupied, encode it as a tile of length 2.
- If the position is unoccupied, encode it as a tile of length 1.

If $t$ positions are occupied, the resulting tiling has total length

$$
2t+(b+1-t)=b+t+1=n+1.
$$

Conversely, take any tiling of length $n+1$ containing $t\ge1$ tiles of length 2.

The tiling contains $n+1-t$ tiles in total. Set

$$
b=n-t.
$$

The $n+1-t=b+1$ tiles specify, in order, which of the $b+1$ possible upper brick positions are occupied.

This constructs a valid two-level tower with $b+t=n$ bricks.

The two constructions are mutually inverse. Hence we have a bijection

$$
\left\{\text{two-level towers with }n\text{ bricks}\right\}
\longleftrightarrow
\left\{\text{tilings of length }n+1\text{ with a length-2 tile}\right\}.
$$

The number of tilings of length $m$ using tiles of lengths 1 and 2 is $F_{m+1}$, by considering the first tile.

Thus there are $F_{n+2}$ tilings of length $n+1$. Exactly one consists entirely of length-1 tiles.

Removing that tiling gives

$$
T(n,2)=F_{n+2}-1.
$$

By the definition of A000071,

$$
\boxed{
T(n,2)=\mathrm{A000071}(n+2)
\quad\text{for every }n>1.
}
$$

**Q.E.D.**

This is an unconditional combinatorial proof. It relies only on the stated domino-tower rules and the elementary Fibonacci tiling recurrence.

## 3. Computational verification

The following Python 3 program independently enumerates permitted second-level placements using geometric overlap, tests the binomial-count lemma, and compares the resulting counts with Fibonacci numbers.

```python

from math import comb

def eligible(b):
    # Base: b adjacent bricks of length 2 in [0, 2*b].
    # Upper bricks have odd-integer left endpoints.
    return [
        x for x in range(-3, 2*b + 2, 2)
        if max(0, min(x+2, 2*b) - max(x, 0)) >= 1
    ]

def direct(n):
    total = 0
    for b in range(1, n):
        slots = eligible(b)
        top = n - b
        total += sum(
            mask.bit_count() == top
            for mask in range(1 << len(slots))
        )
    return total

def formula(n):
    return sum(
        comb(n-t+1, t)
        for t in range(1, (n+1)//2 + 1)
    )

F = [0, 1]
for i in range(2, 203):
    F.append(F[-1] + F[-2])

for b in range(1, 15):
    assert len(eligible(b)) == b + 1
    for t in range(b + 2):
        assert sum(
            mask.bit_count() == t
            for mask in range(1 << (b+1))
        ) == comb(b+1, t)

for n in range(2, 17):
    assert direct(n) == formula(n) == F[n+2] - 1

for n in range(2, 201):
    assert formula(n) == F[n+2] - 1

print('eligible slots and subset counts: b=1..14, t=0..b+1: OK')
print('physical enumeration: n=2..16: OK')
print('binomial sum vs Fibonacci: n=2..200: OK')
print('T(n,2), n=2..16:', [direct(n) for n in range(2, 17)])
print('T(200,2):', formula(200))
```
