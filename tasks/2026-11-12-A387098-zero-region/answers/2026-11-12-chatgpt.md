# A387098 — Status and Proof Report

**Date:** November 12, 2026 **Subject:** Zero region of OEIS A387098 **Verdict:** PROVED — previously known (2024)

## 1. Status and literature search

The conjecture in [OEIS A387098](https://oeis.org/A387098), authored by Hamidreza Maleki Tirabadi (October 16, 2025), states:

> Conjecture: T(n,k) = 0 for n < 4k, except for T(1,1)=1.

The live OEIS entry still labels this statement a conjecture.

**However, a stronger result was already proved in November 2024.**

The decisive source is:

Igor Minevich, Gabe Cunningham, Aditya Karan, and Joshua V. Gyllinsky (2024), *Parks: A Doubly Infinite Family of NP-Complete Puzzles and Generalizations of A002464*, arXiv:2411.02251v1, Section VII, Theorem 3.

[Read the preprint and Theorem 3](https://arxiv.org/abs/2411.02251)

Theorem 3 establishes that, apart from the $1\times1$ exception, the smallest valid board for a $(c,r)$-tree configuration has dimensions $4c\times4r$. It also proves that exactly two tree configurations exist on that minimal board.

The decisive wording is:

> the smallest possible size of grid that can have a valid configuration of trees ... is $4c\times4r$.

The theorem's proof begins with the same adjacent-row counting argument needed for A387098 and explicitly eliminates the $4r-1$ boundary case.

**Why this settles A387098:** A $(c,r)$-tree configuration has exactly $c$ trees per column, exactly $r$ per row, and no two trees touching, even diagonally. Taking $c=r=k$ gives precisely the non-attacking-kings conditions. The additional Parks-puzzle requirement causes no obstruction: any qualifying king placement can be made into a Parks configuration by taking each row as one park.

Thus the theorem applies directly to the square boards counted by A387098.

It proves both:

$$
\boxed{T(n,k)=0\quad\text{for }1<n<4k}
$$

and the stronger boundary identity

$$
\boxed{T(4k,k)=2\quad(k\ge1).}
$$

The $1\times1$ exception is explicitly covered.

**Other sources checked.** I reviewed the OEIS entry, related sequences A002464, A389766, A389770 and A390419, OEIS wiki guidance, and web-indexed arXiv, Zenodo, MathSciNet and zbMATH material, including searches targeting October 15–November 12, 2026. No newer result is needed to establish the theorem's status. Direct searches inside MathSciNet and zbMATH were not available, and the direct arXiv and Zenodo search interfaces were not fully accessible; these are limits on the completeness of the literature search, not on the identified 2024 proof.

There is also a **domain-of-definition issue**: A387098 formally lists only $0\le k\le\lfloor n/4\rfloor+[n=1]$. Consequently, its conjectured zero values fall outside the displayed triangle. The meaningful formulation extends $T(n,k)$ naturally to every nonnegative integer $k$ as a counting function. Under that interpretation, the result is proved.

## 2. Proof and mathematical verification

The following gives a short self-contained proof of the zero region. It reproduces an argument already present in the 2024 paper; it is **not a new proof claim**.

### Theorem

Let $n\ge2$ and $k\ge1$. If an $n\times n$ board contains exactly $k$ non-attacking kings in every row and every column, then

$$
n\ge4k.
$$

### Proof

Consider any two consecutive rows.

Together, they contain $2k$ kings. No two of these kings can lie in the same column or in consecutive columns: otherwise they would attack horizontally, vertically, or diagonally.

Therefore these $2k$ kings occupy $2k$ mutually nonconsecutive columns.

The minimum width accommodating $2k$ nonconsecutive positions is

$$
2(2k)-1=4k-1.
$$

Hence

$$
n\ge4k-1.
$$

We now exclude equality.

Suppose $n=4k-1$. The only possible arrangement of $2k$ mutually nonconsecutive occupied columns is

$$
1,3,5,\ldots,4k-1.
$$

This applies to **every pair of consecutive rows**.

Consequently, every king in every row belongs to an odd-numbered column, because every row appears in at least one consecutive pair.

But the board also requires exactly $k\ge1$ kings in each even-numbered column. Those columns would be empty.

This contradiction eliminates $n=4k-1$.

Therefore

$$
\boxed{n\ge4k.}\qquad\square
$$

The case $n=1$ is separate: $T(1,1)=1$, as required.

### Sharpness

The bound is attained for every $k\ge1$.

Using zero-based column indices, define four sets of $k$ columns:

$$
\begin{aligned}
A&=\{1,3,\ldots,2k-1\},\\
B&=\{2k+1,2k+3,\ldots,4k-1\},\\
C&=\{0,2,\ldots,2k-2\},\\
D&=\{2k,2k+2,\ldots,4k-2\}.
\end{aligned}
$$

Construct the $4k$ rows in the order

$$
(AB)^k(CD)^k.
$$

Here each letter represents the set of columns occupied in that row.

Every row contains $k$ kings, and each of the four column sets occurs in exactly $k$ rows, so every column also contains $k$ kings. Consecutive row sets have horizontal separation at least two columns, including the transition from $B$ to $C$; thus no kings attack.

Reflecting the arrangement horizontally produces a distinct second arrangement.

This independently proves $T(4k,k)\ge2$. The stronger assertion that there are **exactly two** such arrangements is already proved in Theorem 3 of Minevich et al. (2024).

## 3. Computational check

I executed an independent Python enumeration using valid row bitmasks, adjacent-row compatibility, and memoized column counts.

The search does not assume the $4k$ theorem. It enumerates the row possibilities directly and prunes only when a column has too many kings or cannot reach its required count.

```python

from functools import lru_cache
from itertools import combinations

def T(n, k):
    if k == 0:
        return 1

    masks = [
        sum(1 << i for i in c)
        for c in combinations(range(n), k)
        if all(b-a > 1 for a,b in zip(c,c[1:]))
    ]

    after = {
        a: [b for b in masks
            if not (b & (a | (a << 1) | (a >> 1)))]
        for a in masks
    }

    @lru_cache(None)
    def F(r, prev, counts):
        if r == n:
            return int(all(x == k for x in counts))

        choices = masks if r == 0 else after[prev]
        s = 0

        for b in choices:
            c = tuple(
                counts[i] + ((b >> i) & 1)
                for i in range(n)
            )
            if all(x <= k <= x + n-r-1 for x in c):
                s += F(r+1, b, c)

        return s

    return F(0, 0, (0,)*n)

checked = [
    (n,k)
    for n in range(1,13)
    for k in range(1,n+1)
    if n < 4*k and (n,k) != (1,1)
]

zero_bad = [
    (n,k,T(n,k))
    for n,k in checked
    if T(n,k) != 0
]

print("Zero-region pairs checked:", len(checked))
print("Nonzero counterexamples:", zero_bad)
print("Exception T(1,1):", T(1,1))

for k in range(1,4):
    print(f"Boundary T({4*k},{k}):", T(4*k,k))
```
