# OEIS A229232 — Status and Proof Attempt

**Research date:** 12 November 2026 **Problem:** Zhi-Wei Sun’s conjecture on circular permutations with prime adjacent products minus one.

## 1. Status and literature review

**Status: OPEN, as far as the sources examined establish.** The conjecture is mathematically well-posed. I found neither a general proof nor a counterexample for an admissible $n$. The recent results on related finite-field conjectures do not settle this problem.

### Precise statement

For $n\geq 3$, define the graph

$$
G_n=(V_n,E_n),\qquad V_n=\{1,\ldots,n\},
$$

where distinct vertices $u,v$ are adjacent exactly when $uv-1$ is prime.

Then OEIS A229232 counts the Hamiltonian cycles of $G_n$, identifying cycles that differ by rotation or reversal.

The conjecture is precisely

$$
\boxed{\forall n\geq6,\quad n\ne13
\implies G_n\text{ is Hamiltonian}.}
$$

### Primary references

**1. Sun (2019), original conjecture.**

Zhi-Wei Sun, *Some New Problems in Additive Combinatorics*, *Nanjing University Journal of Mathematics Biquarterly* **36** (2019), no. 2, pp. 134–155, Conjecture 3.16 (originally formulated 17 September 2013). Also arXiv:1309.1679v9.

Decisive passage:

> For any integer $n>5$ with $n\ne13$, there is a circular permutation [...] such that [...] are all prime.

This is explicitly presented as Conjecture 3.16, not a theorem. Remark 3.16 gives a valid cycle for $n=23$.

**2. OEIS A229232 (Sun, 2013; extensions in 2025–2026).**

The OEIS record retains the explicit statement:

> Conjecture: a(n) > 0 for all n > 5 with n not equal to 13.

The repository snapshot dated 27 October 2026 contains exact counts through $n=33$. These extensions are credited to Pontus von Brömssen ($n=11,\ldots,21$, January 2025) and Martin Ehrenstein ($n=22,\ldots,33$, October 2026). They establish positive values over a finite range, not the universal conjecture.

The OEIS wiki's conjecture list also records the statement without a resolution.

**3. Luo and She (2026), related but distinct.**

Xin-Qi Luo and Yue-Feng She, *A Conjecture on Circular Permutations over Finite Fields*, arXiv:2610.06289, submitted 5 October 2026, Theorem 1.2.

Their abstract states:

> In this paper, we confirm this conjecture for $q>18\,888\,871$.

Their theorem concerns primitive elements of finite fields, not ordinary prime integers of the form $uv-1$. Thus it does not imply Sun's Conjecture 3.16.

**4. Other recent developments.**

Yue-Feng She, *Hamiltonicity in Graphs Defined by Primes and Primitive Elements*, arXiv:2609.19114 (16 September 2026), proves a sufficiently-large-order result for *prime-sum* circles. The condition is $u+v$ prime, not $uv-1$ prime.

An anonymous October 2026 Zenodo candidate, *A Primitive Circle—with One Exception*, DOI: 10.5281/zenodo.23307915, concerns the finite-field shifted-product problem. Its proposed exception does **not** refute A229232. The candidate itself is described as unrefereed and awaiting independent verification.

## 2. Proof attempt and rigorous partial results

### Proposition 1. Parity structure of every admissible cycle

**Proved.** For $n\geq6$, every Hamiltonian cycle of $G_n$ satisfies:

- If $n$ is odd, the edge $\{1,3\}$ must occur, and no two even vertices are adjacent.
- If $n$ is even, either every edge joins opposite parities, or the cycle contains exactly one odd–odd edge, namely $\{1,3\}$, and exactly one even–even edge.

**Proof.**

Let $u,v$ be distinct odd positive integers. Then $uv-1$ is even. If it is prime, it must equal $2$, giving $uv=3$. Consequently,

$$
\{u,v\}=\{1,3\}.
$$

Thus $\{1,3\}$ is the only possible edge joining two odd vertices.

For a Hamiltonian cycle $C$, let $e_{OO}$, $e_{EE}$, and $e_{OE}$ denote its numbers of odd–odd, even–even, and mixed-parity edges.

Counting incidences at odd and even vertices gives

$$
2|O|=2e_{OO}+e_{OE},
$$

$$
2|E|=2e_{EE}+e_{OE}.
$$

Subtracting yields

$$
e_{OO}-e_{EE}=|O|-|E|.
$$

If $n$ is odd, the right-hand side is $1$. Since $e_{OO}\leq1$, necessarily

$$
e_{OO}=1,\qquad e_{EE}=0.
$$

If $n$ is even, the right-hand side is zero, so

$$
e_{OO}=e_{EE}\in\{0,1\}.
$$

This proves both assertions. $\square$

**Consequence.** For odd $n$, a Hamiltonian-cycle search can fix the initial vertices as $(1,3)$. This removes an important source of wasted backtracking. It is a structural reduction, not a proof of existence.

### Proposition 2. The exceptional value $n=13$

**Proved (already known in OEIS).**

For $j\in\{1,\ldots,12\}$, the only value making $13j-1$ prime is $j=8$, which gives

$$
13\cdot8-1=103.
$$

Thus vertex $13$ has degree one in $G_{13}$, whereas every vertex of a Hamiltonian cycle must have two distinct neighbours.

Hence

$$
\boxed{a(13)=0.}
$$

This obstruction is already recorded in the OEIS entry and is **not a new result**.

### Verification program

The following Python 3 program performs both checks. For odd $n$, it uses Proposition 1 to fix the beginning of the cycle as $(1,3)$.

```python

import hashlib
import math
import sys

LIMIT = 600
sys.setrecursionlimit(LIMIT + 100)

prime = bytearray(b'\1') * (LIMIT*LIMIT + 1)
prime[:2] = b'\0\0'

for p in range(2, math.isqrt(LIMIT*LIMIT) + 1):
    if prime[p]:
        prime[p*p::p] = (
            b'\0' * ((LIMIT*LIMIT - p*p)//p + 1)
        )

def neighbors(n):
    return [[]] + [
        [w for w in range(1, n+1)
         if w != v and prime[v*w - 1]]
        for v in range(1, n+1)
    ]

def find_cycle(n):
    adj = neighbors(n)
    if any(len(adj[v]) < 2 for v in range(1, n+1)):
        return None

    path = [1, 3] if n % 2 else [1]
    used = [False] * (n+1)
    for v in path:
        used[v] = True

    def dfs(v):
        if len(path) == n:
            return bool(prime[v-1])

        candidates = (
            w for w in adj[v] if not used[w]
        )
        for w in sorted(
            candidates,
            key=lambda w: (
                sum(not used[x] for x in adj[w]), w
            )
        ):
            used[w] = True
            path.append(w)
            if dfs(w):
                return True
            path.pop()
            used[w] = False
        return False

    return path.copy() if dfs(path[-1]) else None

def count_cycles(n):
    adj = neighbors(n)
    path = [1, 3] if n % 2 else [1]
    used = [False] * (n+1)
    for v in path:
        used[v] = True

    total = 0

    def dfs(v):
        nonlocal total
        if len(path) == n:
            if prime[v-1] and (
                n % 2 or path[1] < path[-1]
            ):
                total += 1
            return

        for w in adj[v]:
            if not used[w]:
                used[w] = True
                path.append(w)
                dfs(w)
                path.pop()
                used[w] = False

    dfs(path[-1])
    return total

print(
    'counts n=6..17:',
    [count_cycles(n) for n in range(6, 18)]
)

h = hashlib.sha256()
checked = 0

for n in range(6, LIMIT+1):
    if n == 13:
        nbrs = [
            j for j in range(1, 13)
            if prime[13*j - 1]
        ]
        assert nbrs == [8]
        continue

    cycle = find_cycle(n)
    assert cycle is not None, n
    assert len(cycle) == n
    assert set(cycle) == set(range(1, n+1))
    assert all(
        prime[cycle[i]*cycle[(i+1) % n] - 1]
        for i in range(n)
    )

    line = str(n) + ':' + ','.join(
        map(str, cycle)
    ) + '\n'
    h.update(line.encode())
    checked += 1

print('exception n=13: neighbors of 13 =', nbrs)
print('certified positive range: 6..600 excluding 13')
print('successful values:', checked)
print('SHA256 (n:cycle lines):', h.hexdigest())
print('n=600 first 20 vertices:', cycle[:20])
print('n=600 last 20 vertices:', cycle[-20:])
```

The count verification fixes the edge (1,3) for odd n and fixes the orientation by requiring the second vertex to be smaller than the last for even n. Each undirected cycle is therefore counted exactly once.
